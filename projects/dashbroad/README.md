# 化學雲申請帳號數量分析圖表

這是一個用於展示化學雲申請帳號數量的時間序列圖表應用。

## 功能特點

- 展示化學雲申請帳號數量的時間序列圖表（x軸時間，y軸數量）
- 支持按不同角色篩選數據：消防單位、經濟部、勞動部、衛福部、環境部
- 提供更詳細的子單位篩選功能，如消防局、產業發展署等具體單位
- 支持同時選擇多個單位進行比較分析
- 支持不同時間頻率的數據統計：月、季、年
- 可根據帳號狀況進行篩選：活躍/非活躍
- 可設定日期範圍

## 如何使用

1. 在瀏覽器中打開 `index.html` 文件。
2. 使用篩選面板調整要顯示的數據：
   - 選擇時間頻率（月、季、年）
   - 選擇帳號狀態（全部、活躍、非活躍）
   - 設定要分析的日期範圍
   - 選擇要顯示的單位（可多選）
3. 點擊「顯示詳細單位」可以切換到更細緻的單位選擇：
   - 可選擇特定的子單位，如消防局、產業發展署等
   - 支持同時選擇多個不同部門的子單位
   - 每個部門提供「全選」功能方便操作
4. 點擊「套用篩選」按鈕更新圖表。
5. 可隨時使用「重置篩選」按鈕恢復默認設置。

## 特別應用案例

- **同時查看特定單位使用狀況**：例如，可以同時選擇「消防局」和「產業發展署」來比較這兩個單位的帳號使用狀況。
- **按狀態分析**：可選擇只查看活躍或非活躍帳號，分析不同單位的帳號活躍度。
- **時間趨勢分析**：透過更改時間頻率，可分析月度、季度或年度的變化趨勢。

## 技術說明

- 使用 HTML 和 JavaScript 實現
- 圖表繪製使用 Chart.js 庫
- 使用 Bootstrap 5 進行頁面樣式設計
- 當前使用的是模擬數據，實際應用中需替換為真實的數據源

## 注意事項

- 當前版本使用模擬數據進行展示
- 在生產環境中使用時，需要修改 `generateMockData()` 函數，連接真實的數據源
