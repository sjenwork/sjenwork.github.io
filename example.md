| **時代**    | **工作流程描述**                                                                                                                                                                                                                                |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 完全人工作業    | 收到信件人工打開信件、轉寄、下載附件，並進行人工彙整。                                                                                                                                                                                                               |
| 人工設定自動化   | * 基於規則篩選轉寄（Gmail 篩選器）。<br> * Gmail 外掛自動放置於雲端資料夾。                                                                                                                                                                                          |
| AI 輔助型自動化 | * **透過 n8n、Make 等工具，以拖拉、節點、串接的方式，結合 NLP (例如 OpenAI)，判斷郵件內容，決定是否屬於特定類型信件並轉寄。**<br> * 自動存放於雲端資料夾。<br> * 可自動化建立檔案歸檔。<br> * 強調「人機協作」的概念，AI 負責處理重複性、規則性的工作，而人類負責處理複雜、需要判斷的情況。<br> * 「AI 的錯誤率」和「異常處理機制」是實際應用中必須考慮的問題。<br> * 增加對資料安全的提醒。<br><br> |
| AI 自動型    | * 藉由大型語言模型，自動判斷郵件類型、內容摘要、附件內容分析、自動分類歸檔，並且自動產出後續使用報表。 <br> * 可根據郵件內容自動判斷相關人員並轉發，並且總結郵件以及附件檔案，自動產出報表。                                                                                                                                       |
